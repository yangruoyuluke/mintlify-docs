# Mintlify 文档仓库结构说明（v2）

更新时间：2026-05-22

## 1. 本次更新目标

本版本基于 `https://admin.marsmind.cc/login` 的真实后台界面，重新梳理中文管理后台操作指南。更新重点是补强新版后台的左侧导航、右上角帮助中心、助手设置、知识库拆分流程、技能库、线索清洗折叠展开、工作时间和数据导出说明。

## 2. 更新范围

本次保持 `docs.json` 导航结构不变，只更新中文 `/cn/admin-backend` 下的现有 6 个页面。

| 文件 | 更新重点 |
| :--- | :--- |
| `cn/admin-backend/login-and-registration.mdx` | 登录、注册、新版后台导航、右上角帮助中心、语言切换、账号设置 |
| `cn/admin-backend/run-avatar.mdx` | 登录上线、创建沟通窗口、响应设定 |
| `cn/admin-backend/qa-management.mdx` | 知识生成、知识录入、知识审核、知识维护、知识分组设定、技能库 |
| `cn/admin-backend/identity-setup.mdx` | 关系配置、筛选、批量设为客户/同事/静默/主管 |
| `cn/admin-backend/inbound-setup.mdx` | 自动接受好友、新好友欢迎语、线索清洗、工作时间 |
| `cn/admin-backend/data-module.mdx` | 业务表现、核心指标、趋势分析、数据导出 |

主要截图包括登录页、业务表现、数据导出、助手设置二级页、知识库五个子页、技能库、帮助中心、语言菜单、沟通窗口弹窗、线索清洗展开态、知识生成/录入列表展开态和批量操作态。

## 5. 设计规范

本次新增 `DESIGN.md`，用于约束后续文档编辑。

核心要求如下。

- 截图保留左侧导航和当前操作区，便于定位。
- 图片统一存放于 `/images/admin-backend/`。
- 使用 `<Steps>` 表达操作步骤。
- 使用 `<Warning>` 标记保存、删除、导出、授权码等高风险事项。
- 内容表达保持简洁、准确、可执行。

## 6. 后续建议

英文和日文后台指南目前仍沿用旧内容。若需要三语一致，建议以本次中文版本为源文档，后续创建 v3 版本完成英文和日文同步。

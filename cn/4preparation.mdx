### 1. 真实对话10\+组

您的业务场景常见的对话沟通记录。可以是您的目前的业务员目前在这个业务场景中的典型沟通对话记录。需要完整不作删减，至少10组，越多越好。沟通效果可以是成交或者未成交均可， 最重要的是足够典型，可以让您的角色学习到典型的客户问题和对应话术。建议包含销售的操作动作过程也体现出来。

<Tabs>
  <Tab title="一组样例参考1">
    **客户**：你好，我想在你们平台开店，请问需要准备什么？\
    **销售**：您好，需要三份资料：企业营业执照、法人身份证明和收款账户信息。（发送标准指引海报）\
    **客户**：我刚刚上传了，你能帮我看看吗？\
    **销售**：好的，我帮您确认。（登录后台查询上传记录）\
    **销售**：我看到三份资料都已提交完整，状态是“待审核”。\
    **客户**：审核一般多久？\
    **销售**：通常 3–5 个工作日。如果有缺失，系统会提示您重新补交。\
    **客户**：好的，那通过以后要怎么做？\
    **销售**：审核通过后，我们会为您创建卖家账号。（后台生成账号 → 将账号信息发送至客户邮箱）\
    **客户**：我收到了账号邮件，已经能登录后台了。\
    **销售**：很好，您只需要填写店铺信息并上传产品，就可以正式上线。\
    **客户**：已经提交了，显示在“待审核”。\
    **销售**：是的，产品内容审核一般 2–3 小时就会放行，您的店铺很快就能上线了。
    **客户**：好的，谢谢您。
  </Tab>
  <Tab title="一组样例参考2">
    **客户**：你好，我是国外用户，想在你们这里注册虚拟信用卡，请问需要什么资料？\
    **销售**：您好，注册需要您的护照信息、邮箱地址以及一张可绑定的银行卡。（发送注册指引页面链接）\
    **客户**：好的，我刚刚提交了护照和银行卡，你能帮我确认一下吗？\
    **销售**：没问题，我这边帮您查看。（登录后台 → 输入客户邮箱 → 查询提交的注册资料）\
    **销售**：我看到您的护照和银行卡信息已经上传成功，状态显示“待审核”。\
    **客户**：审核一般多久？\
    **销售**：通常 1–2 个工作日，如果资料不符合，系统会发送邮件提醒您重新提交。\
    **客户**：通过审核后，我要怎么开卡？\
    **销售**：审核通过后，我们会为您生成虚拟信用卡号，并通过邮箱发给您。（后台生成卡号 → 系统自动发送邮件）\
    **客户**：那卡片可以马上使用吗？\
    **销售**：是的，您只需要在后台完成激活，就可以在线支付或绑定电商平台。\
    **客户**：结算是怎么处理的？\
    **销售**：消费结算会自动从您绑定的银行卡扣款，账单周期为每月一次。\
    **客户**：明白了，谢谢你。\
    **销售**：不客气，稍后我会持续关注您的审核进度，并第一时间通知您。
  </Tab>
  <Tab title="样例参考3">
    **客户**：你好，我上周在东京购物时办理了退税，想问一下什么时候能到账？\
    **销售**：您好，我帮您查一下退税进度。（登录退税系统 → 输入客户护照号 → 查询退税申请记录）\
    **销售**：系统显示您的退税申请已提交，目前状态是“税务机构审核中”。\
    **客户**：这个阶段一般多久？\
    **销售**：通常需要 5–10 个工作日完成审核。审核通过后，金额会退回到您填写的银行卡账户。\
    **客户**：退税金额会全部到账吗？\
    **销售**：会扣除退税服务费，大约是金额的 2%–3%，其余部分会全额退回。\
    **客户**：我能自己查询吗？\
    **销售**：可以，您在退税凭条上有查询网址和编号，输入之后就能看到进度。（销售截图系统查询页面 → 发送给客户）\
    **客户**：如果超过十天还没有到账呢？\
    **销售**：您可以联系我们客服，我们会帮您提交“退税延迟”申请，由日本退税机构核实处理。\
    **客户**：到账后会有提示吗？\
    **销售**：是的，银行会有入账短信通知，您也会收到退税机构的邮件提醒。\
    **客户**：好的，那我等消息。\
    **销售**：没问题，我会持续关注您的退税进度，有结果会第一时间通知您。
  </Tab>
</Tabs>

### 2. 企业文档知识/官网

可以是您企业的知识文件，需要AI记录响应的知识。最好是以QA的方式呈现，例如提供《常见问答QA表/FAQ表》，以问题和答案的方式提供。一个问题对应一个答案。理想情况是提供符合日常语言表达的内容，而不是官方的书面表达。

<Tabs>
  <Tab title="参考样例">
    | 问题 Question     | 答案 Answer                                                                |
    | :-------------- | :----------------------------------------------------------------------- |
    | 注册需要哪些资料？       | 一般需要提供有效身份证明（护照/身份证）、联系方式、支付账户；若为企业卖家，还需提供营业执照及法人信息。                     |
    | 你们适合哪些行业或人群？    | 平台/服务适合电商卖家、跨境出口企业、旅游消费用户，以及医疗、教育等需要线上预约或结算的群体。                          |
    | 资质审核严格吗？        | 卖家审核 3–5 个工作日完成，只要资料合规都没问题的。                                             |
    | 审核/处理进度如何查询？    | 用户可通过后台“进度查询”功能实时查看状态；如为医疗预约，可通过医院/平台 App 查询；如为退税申请，可在专用系统跟踪进度。          |
    | 退税流程是怎样的？       | 以日本购物退税为例：购物满额后在商家柜台/退税窗口提交护照和发票，办理退税手续；平台类退税则需提交发票、报关单与申请表，审核后款项退回支付账户。 |
    | 医疗预约怎么操作？       | 用户需先在平台选择医院科室和时间，提交身份证件和病历信息，确认后即可生成预约号，部分项目需预缴费用。                       |
    | 平台/服务佣金或手续费是多少？ | 根据业务不同收取：电商销售佣金一般 5%–15%；旅游退税通常收取 1%–3% 服务费；医疗预约手续费视医院政策而定。              |
    | 回款或退款周期多久？      | 电商卖家货款周期为 7–14 天；款项一般在 5–20 个工作日到账；取消预约退款需 3–7 个工作日处理。                   |
    | 如果遇到延迟或问题怎么办？   | 可通过后台“进度查询”或提交工单联系客服；医疗类可拨打医院客服热线；退税问题可携带发票与凭证前往服务点或通过线上申诉。              |
    | 支持哪些语言服务呢？      | 系统支持中文、英文，部分场景支持日语、韩语等多语言，以方便跨境用户操作。                                     |

### 3. 专项AI导师对接人

请企业指定一位专项对接人，实现上线进展对接与AI训练，他将会被定义成为AI的导师（Leader），并且获得导师权限。他将负责AI的后续辅导，也就是，当AI遇到日常问题，将会过来与他汇报请教。日报周报AI也会默认开始发送到这位作为Leader同事这里。当然，您也可以随时选择更换更合适的导师，以实现更好的AI训练效果。

### 4. 现有需要进入的业务流程图

使得AI理解目前业务工作的流程图，方便AI角色理解的流程图。要求顺序推进的业务运转流程，含有关键节点和对应部门（或成员）划分。例如A部门处理后，在X节点转换至B部门。请根据您的具体情况补充。可以使用简单的自然语言，建议使用流程图呈现。

<Tabs>
  <Tab title="自然语言表达参考样例">
    **销售部**

    1. 销售人员接收卖家咨询。
    2. 向卖家说明平台入驻政策和所需资料。
    3. 协助卖家收集并提交资料。\
       → 资料提交后，流程转交给 **审核部**。

    **审核部**\
    4. 审核人员检查资料完整性。\
    　- 如果不完整 → 返回销售部，请卖家补充。\
    　- 如果完整 → 进入下一步。\
    5. 审核人员核查合规性和资质。\
    　- 如果未通过 → 通知客服部反馈卖家。\
    　- 如果通过 → 转交运营部。

    **运营部**\
    6. 创建卖家账号。\
    7. 开通店铺，并完成上线。\
    → 上线后，流程转交给 **客服部**。

    **客服部**\
    8. 客服人员通知卖家审核结果。\
    9. 提供后续运营支持和培训。\
    → 完成闭环。
  </Tab>

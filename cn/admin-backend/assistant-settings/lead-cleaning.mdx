## 功能概览

“线索清洗”用于处理新客户进入后的第一段交互。它可以自动通过好友申请、发送欢迎语，并让 AI 在对话中采集客户关键信息。

## 操作路径

在左侧导航点击 **助手设置 → 线索清洗**。

## 三个核心开关

| 开关 | 说明 |
| :--- | :--- |
| 自动接受新好友申请 | 开启后，系统会自动接受所有好友申请 |
| 新好友欢迎语 | 开启后，可配置新好友首次对话时发送的欢迎消息 |
| 线索清洗 | 开启后，AI 会在对话中采集关键信息，并在 10 轮对话内尽量补齐 |

## 配置欢迎语

<Steps>
  <Step title="开启新好友欢迎语">
    打开“新好友欢迎语”开关，页面会展开欢迎语配置区域。
  </Step>
  <Step title="填写第 1 条欢迎语">
    输入问候、服务说明或下一步引导。
  </Step>
  <Step title="添加更多欢迎语">
    点击“添加新行”继续增加欢迎语。
  </Step>
  <Step title="保存配置">
    点击“保存”使欢迎语生效。
  </Step>
</Steps>

## 配置线索字段

线索字段建议围绕销售判断和后续跟进设计。

| 字段示例 | 采集目的 | 示例 |
| :--- | :--- | :--- |
| 邮箱 | 后续沟通和资料发送 | `name@example.com` |
| 公司名称 | 建立客户画像 | `MarsMind` |
| 主营类目 | 判断业务场景 | 家居、宠物、3C |
| 年销售额 | 判断客户体量 | `1000万人民币` |
| 当前痛点 | 判断服务切入点 | 回复慢、资料分散、线索难跟进 |

<Warning>
  字段不要过多。首次对话中过度采集会降低客户回复率，建议只保留对销售判断最关键的信息。
</Warning>

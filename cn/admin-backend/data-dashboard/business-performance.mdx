## 功能概览

“业务表现”用于观察 AI 助手在当前账号、窗口和时间范围内的沟通效果。它不是配置页，而是复盘页。

<Frame>
  ![业务表现页面，包含窗口筛选、日期筛选、按天周月切换、核心指标和趋势区域](/images/admin-backend/02-dashboard-business-performance.png)
</Frame>

## 操作路径

在左侧导航点击 **数据看板 → 业务表现**。

## 筛选数据范围

| 筛选项 | 说明 |
| :--- | :--- |
| 窗口 | 选择全部窗口或某个具体沟通窗口 |
| 日期 | 选择需要查看的数据日期 |
| 按天、按周、按月 | 切换数据聚合维度 |
| 清除 | 清空当前日期筛选 |

<Info>
  页面中的“当前筛选”会显示当前账号、窗口和日期。判断数据是否异常前，先确认筛选范围是否正确。
</Info>

## 核心指标说明

| 指标 | 业务含义 |
| :--- | :--- |
| 接收量 | 当前范围内收到的消息数量 |
| 问询量 | 被识别为客户问题或咨询的消息数量 |
| 回复量 | AI 或坐席已回复的数量 |
| 建议量 | AI 给出的建议或辅助结果数量 |
| 学习量 | 进入学习或知识沉淀流程的数量 |
| 问询率 | 客户消息中形成明确问题的比例 |
| 回复率 | 问题被响应的比例 |
| 采用率 | AI 建议被采纳或有效使用的比例 |

## 看趋势和问题分布

页面下方通常用于复盘三个问题。

| 区域 | 你应该看什么 |
| :--- | :--- |
| 数量变化趋势 | 消息和回复是否在某天明显升高或降低 |
| 最活跃的群组用户 | 哪些群或用户产生最多沟通 |
| 问题分布 | 客户最常问的是一级问题还是二级问题中的哪类 |

<Tip>
  如果页面显示暂无数据，优先调整日期和窗口。很多时候不是系统异常，而是当前筛选范围没有产生沟通记录。
</Tip>

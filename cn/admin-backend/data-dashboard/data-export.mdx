## 功能概览

“数据导出”用于查看和导出沟通明细。它适合做客户沟通复盘、质检、人工坐席协同分析和内部归档。

<Frame>
  ![数据导出页面，包含沟通数据详情、坐席混合数据、最近 30 天、用户名、群名、用户问询内容和 AI 响应内容筛选项](/images/admin-backend/03-dashboard-data-export.png)
</Frame>

## 操作路径

在左侧导航点击 **数据看板 → 数据导出**。

## 查询明细

<Steps>
  <Step title="选择数据类型">
    选择“沟通数据详情”或“坐席混合数据”。
  </Step>
  <Step title="选择时间范围">
    默认可查看最近 30 天，也可以按业务需要调整。
  </Step>
  <Step title="输入筛选条件">
    可按用户名、群名、用户问询内容、AI 响应内容和响应状态过滤。
  </Step>
  <Step title="点击搜索">
    页面下方表格会按筛选条件展示明细。
  </Step>
  <Step title="导出数据">
    确认筛选结果后点击“导出”。
  </Step>
</Steps>

## 字段说明

| 字段 | 说明 |
| :--- | :--- |
| 时间 | 消息产生或记录生成时间 |
| 用户 | 发起问询的用户 |
| 群 | 消息所在群或会话来源 |
| 用户问询 | 客户原始问题或咨询内容 |
| AI 响应 | AI 的回复或处理内容 |

<Warning>
  导出内容可能包含客户沟通信息。导出、转发或上传到其他系统前，请确认接收方具备查看权限。
</Warning>

## 功能概览

“订单用量”用于查看账户资源消耗和积分余额。它适合运营人员判断当前 AI 服务是否存在余额风险，以及不同能力的消耗占比。

## 你可以查看什么

| 区域 | 说明 |
| :--- | :--- |
| 积分概览 | 查看当前账户剩余积分和总体消耗情况 |
| 消耗明细 | 查看不同能力产生的资源消耗 |
| 用量趋势 | 判断近期消耗是否明显升高 |
| 业务判断 | 判断当前处于知识建设期还是稳定回复期 |

## 使用建议

<Steps>
  <Step title="进入订单用量">
    在左侧导航进入 **数据看板 → 订单用量**。
  </Step>
  <Step title="查看余额">
    先确认当前积分余额是否足够支撑近期使用。
  </Step>
  <Step title="查看消耗构成">
    对比回复生成、知识生成和其他能力的消耗比例。
  </Step>
  <Step title="安排补充或优化">
    如果消耗异常升高，需要检查是否有大量知识生成、异常对话或测试流量。
  </Step>
</Steps>

<Tip>
  通过分析“回复生成消耗”和“知识生成消耗”的比例，你可以判断当前是知识建设期，还是业务稳定运行期。
</Tip>

## 功能概览

“业务表现”不是配置页，而是复盘页。你可以用它判断 AI 最近有没有正常服务、客户问题是否集中在某些主题、以及哪些窗口或群聊最活跃。

<Frame>
  ![业务表现页面，包含窗口筛选、日期筛选、按天周月切换、核心指标和趋势区域](/images/admin-backend/02-dashboard-business-performance.png)
</Frame>

## 操作路径

在左侧导航点击 **数据看板 → 业务表现**。

## 先确认你在看哪一段数据

复盘前先选窗口和日期。看日常波动时用按天，做周会复盘时用按周，观察长期趋势时再切到按月。不要在筛选范围还不清楚时判断“AI 表现变差”，很多异常只是窗口或日期选错了。

<Info>
  页面中的“当前筛选”会显示当前账号、窗口和日期。判断数据是否异常前，先确认筛选范围是否正确。
</Info>

## 先看三个核心判断

<Steps>
  <Step title="先看接收量和问询量">
    接收量代表消息规模，问询量代表真正形成咨询的问题规模。如果接收量高但问询量低，可能是闲聊、通知或无关消息更多。
  </Step>
  <Step title="再看回复率和采用率">
    回复率低时，先检查工作时间、关系配置和静默设置。采用率低时，通常要回到响应设定、知识库或技能逻辑里找原因。
  </Step>
  <Step title="最后看学习量">
    学习量上升不一定是坏事，它可能说明客户出现了新问题。要判断这些问题是否应该沉淀进知识库。
  </Step>
</Steps>

## 指标含义

| 指标 | 你应该怎么理解 |
| :--- | :--- |
| 接收量 | 当前范围内收到的消息数量 |
| 问询量 | 被识别为客户问题或咨询的消息数量 |
| 回复量 | AI 或坐席已回复的数量 |
| 建议量 | AI 给出的建议或辅助结果数量 |
| 学习量 | 进入学习或知识沉淀流程的数量 |
| 问询率 | 客户消息中形成明确问题的比例 |
| 回复率 | 问题被响应的比例 |
| 采用率 | AI 建议被采纳或有效使用的比例 |

## 看趋势和问题分布

页面下方适合回答三个复盘问题：哪天消息突然变化、哪些群或用户最活跃、客户最常问的是哪类问题。看到异常后，不要只停在数据页；下一步应该去知识库、响应设定或关系配置里处理原因。

<Tip>
  如果页面显示暂无数据，优先调整日期和窗口。很多时候不是系统异常，而是当前筛选范围没有产生沟通记录。
</Tip>

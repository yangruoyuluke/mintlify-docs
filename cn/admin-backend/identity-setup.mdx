## 功能说明

“关系配置”用于告诉 AI 助手如何识别不同联系人或群聊。正确的关系配置可以避免 AI 把内部同事当成客户，也可以让 AI 在不适合发言的群中保持静默。

常见关系包括客户、同事、静默和主管。

## 操作路径

在左侧导航点击 **助手设置 → 关系配置**。

页面包含选择沟通窗口、快速筛选、批量关系设置和联系人列表四个区域。

| 区域 | 用途 |
| :--- | :--- |
| 选择沟通窗口 | 选择要管理的账号或窗口 |
| 快速筛选 | 按好友/群昵称、单聊及群聊、关系和标签过滤对象 |
| 批量关系设置 | 将选中对象设为客户、同事、静默或主管 |
| 联系人列表 | 查看昵称、头像、群/单聊、标签和当前关系 |

## 查询好友或群

<Steps>
  <Step title="选择账号范围">
    在“选择沟通窗口”中选择全部账号或某个具体窗口。
  </Step>
  <Step title="输入昵称关键词">
    在“好友/群昵称”中输入关键词。
  </Step>
  <Step title="选择类型和关系">
    可按单聊及群聊、全部关系或具体关系继续缩小范围。
  </Step>
  <Step title="点击搜索">
    点击“搜索”后，列表会展示匹配结果。
  </Step>
</Steps>

## 设置关系

在列表中勾选需要调整的联系人或群聊，然后点击对应按钮。

| 操作 | 适用场景 |
| :--- | :--- |
| 设为客户 | 对方是客户或潜在客户，AI 可以正常服务和回复 |
| 设为同事 | 对方是内部协作人员，AI 应按协作对象理解 |
| 设为静默 | AI 仅监听或记录，不主动发言 |
| 设为主管 | 对方是需要接收汇报或管理信息的角色 |

<Info>
  “刷新列表”每自然日 0:00 到 24:00 最多点击一次。联系人刚同步后如果列表为空，可以先确认沟通窗口是否在线，再等待同步完成。
</Info>

## 配置建议

<AccordionGroup>
  <Accordion title="客户群">
    将客户群设为客户关系，让 AI 按服务和销售场景回复。
  </Accordion>
  <Accordion title="内部群">
    将内部群设为同事或主管关系，避免 AI 使用客户服务口径回应内部讨论。
  </Accordion>
  <Accordion title="观察群">
    对不希望 AI 发言的群设置静默，让 AI 不主动参与对话。
  </Accordion>
</AccordionGroup>

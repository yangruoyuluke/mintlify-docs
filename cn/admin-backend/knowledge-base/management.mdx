## 功能概览

知识管理用于维护已经生成、录入或等待确认的知识。它包含审核、维护和分组三类日常工作。

## 审核待确认知识

进入 **知识库 → 知识审核**，检查待审核内容并决定接受或丢弃。

<Frame>
  ![知识审核页面，包含待审核说明、来源筛选、批量接受和批量丢弃按钮](/images/admin-backend/14-knowledge-review.png)
</Frame>

## 维护已入库知识

进入 **知识库 → 知识管理**，搜索和维护已经入库的知识。

<Frame>
  ![知识维护页面，支持搜索、批量操作、知识归属筛选、QA 和段落知识筛选](/images/admin-backend/15-knowledge-maintenance.png)
</Frame>

常用操作包括：

| 操作 | 说明 |
| :--- | :--- |
| 搜索 | 按关键词查找知识 |
| 筛选 | 按企业/个人、QA/段落、分组和来源过滤 |
| 批量删除 | 删除不再需要或错误的知识 |
| 修改分组 | 把知识移动到更合适的分组 |
| 翻页查看 | 查看更多入库内容 |

## 管理知识分组

知识分组用于让生成、录入、审核和维护都能按业务场景归类。

<Frame>
  ![知识分组设定页面，展示业务知识、产品知识、MarsMind AI 等分组及生效状态开关](/images/admin-backend/16-knowledge-group-settings.png)
</Frame>

<Warning>
  批量删除会影响 AI 后续回答的知识来源。执行前请确认搜索条件、筛选条件和勾选范围。
</Warning>

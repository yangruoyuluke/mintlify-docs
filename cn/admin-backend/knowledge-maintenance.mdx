## 功能概览

“知识维护”是日常管理已入库知识的主页面。你可以在这里搜索知识、查看来源、筛选类型、批量删除或修改分组。

<Frame>
  ![知识维护页面，支持搜索、批量操作、知识归属筛选、QA 和段落知识筛选](/images/admin-backend/15-knowledge-maintenance.png)
</Frame>

## 操作路径

在左侧导航点击 **知识库 → 知识维护**。

## 常用筛选

| 筛选项 | 用途 |
| :--- | :--- |
| 搜索框 | 按关键词搜索知识内容 |
| 企业知识库 / 个人知识库 | 切换知识归属 |
| QA知识 / 段落知识 | 切换知识类型 |
| 全部知识 | 按分组或知识范围过滤 |
| 全部来源 | 按文档、网页、录入等来源过滤 |

## 批量操作

点击“批量操作”后，页面会显示批量删除和修改分组入口。

<Frame>
  ![知识维护页面开启批量操作后，显示批量删除和修改分组按钮](/images/admin-backend/29-knowledge-maintenance-batch-actions.png)
</Frame>

<Warning>
  批量删除会影响 AI 后续回答的知识来源。执行删除前，请确认搜索条件、筛选条件和勾选范围。
</Warning>

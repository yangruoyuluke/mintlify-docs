## 后台能做什么

MarsMind 管理后台用于把 AI 助手从“能登录”配置到“能稳定服务客户”。你通常会在这里完成上线、回复规则、关系识别、线索采集、知识库、技能库和数据复盘。

## 真实菜单结构

| 后台模块 | 你在这里完成什么 |
| :--- | :--- |
| 数据看板 | 看业务表现，按条件导出沟通明细 |
| 助手设置 | 让 AI 助手上线，配置回复规则、关系、线索清洗和工作时间 |
| 技能库（Beta） | 配置 AI 处理特定业务任务时的执行方法和可调用工具 |
| 知识库 | 从文档或网页生成知识，手动录入知识，审核和维护入库内容 |
| 网页聊天 | 在网页中测试或使用聊天能力 |
| 操作指南 | 使用后台内置的模块化引导 |
| 账号设置 | 管理 AI 授权码、后台密码和退出登录 |

## 推荐配置顺序

<Steps>
  <Step title="登录后台">
    先进入后台并确认当前账号、语言和帮助中心入口正常可用。
  </Step>
  <Step title="创建沟通窗口并上线">
    进入“助手设置 → 登录上线”，创建新的沟通窗口并完成授权。
  </Step>
  <Step title="配置回复规则">
    进入“助手设置 → 响应设定”，写清 AI 的角色定位、回复边界和群聊判断逻辑。
  </Step>
  <Step title="配置关系和接入规则">
    进入“关系配置”和“线索清洗”，明确客户、同事、静默对象和新客户欢迎语。
  </Step>
  <Step title="建立知识和技能">
    使用知识库沉淀标准内容，使用技能库定义复杂业务动作。
  </Step>
  <Step title="用数据复盘">
    进入数据看板查看业务表现，并在需要时导出明细。
  </Step>
</Steps>

<Tip>
  如果你是第一次配置，建议按上面的顺序推进。不要先大量上传知识，再回头补角色设定，因为 AI 的回复口径会同时受“响应设定”和“知识库”影响。
</Tip>

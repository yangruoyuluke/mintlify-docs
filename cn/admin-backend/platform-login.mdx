## 账户登录

MarsMind 管理后台用于配置 AI 助手、知识库、技能库、数据看板和网页聊天等能力。中国用户建议使用 `.cc` 后台地址。

<Steps>
  <Step title="打开登录页">
    进入 [https://admin.marsmind.cc/login](https://admin.marsmind.cc/login)。海外环境可使用 [https://admin.marsmind.co/](https://admin.marsmind.co/#/login?redirect=%2Findex)。
  </Step>
  <Step title="输入账户信息">
    输入你的用户名和密码。如果你不确定账户信息，请联系业务经理或系统管理员。
  </Step>
  <Step title="点击登录">
    登录成功后会进入新版管理后台，默认展示数据看板中的业务表现页。
  </Step>
</Steps>

<Frame>
  ![MarsMind 管理后台登录页，包含用户名、密码和注册入口](/images/admin-backend/01-login-page.png)
</Frame>

<Note>
  登录页右上角可以切换语言。当前后台支持中文、English 和日本語。
</Note>

## 账户注册

如果你是第一次使用系统，或企业为你开通了新账户，可以在登录面板中点击“注册”切换到注册页面。

<Steps>
  <Step title="切换到注册">
    在登录页点击“注册”。
  </Step>
  <Step title="填写注册信息">
    依次填写用户名、密码、确认密码和邀请码。
  </Step>
  <Step title="同意协议并提交">
    勾选同意条款后点击注册。
  </Step>
</Steps>

<Frame>
  ![MarsMind 注册页面，包含用户名、密码、确认密码和邀请码输入项](/images/invitationreg.png)
</Frame>

<Warning>
  当前系统仅支持邀请码注册或企业后台开通，不支持完全开放注册。如需开通账户，请联系 [sales@marsmind.co](mailto:sales@marsmind.co)。
</Warning>

## 新版后台整体结构

登录后，页面左侧是主导航，右侧是当前功能页。新版后台按操作目的划分为以下模块。

| 模块 | 主要用途 |
| :--- | :--- |
| 数据看板 | 查看业务表现、导出沟通数据 |
| 助手设置 | 登录上线、响应设定、关系配置、线索清洗、工作时间 |
| 技能库（Beta） | 管理 AI 助手可调用的业务技能和工具能力 |
| 知识库 | 生成、录入、审核、维护和分组知识 |
| 网页聊天 | 在网页内测试或使用聊天入口 |
| 操作指南 | 查看后台内置操作引导 |
| 账号设置 | 管理授权码、后台登录密码和退出登录 |

## 右上角常用入口

后台右上角提供三个高频入口，适合在操作过程中快速切换上下文。

| 入口 | 用途 |
| :--- | :--- |
| 我的 AI 助手 | 快速查看或切换当前助手上下文 |
| 帮助中心 | 打开按模块划分的操作引导，可从数据看板、助手设置、技能库、知识库和初始化配置开始 |
| 语言 | 切换中文、English、日本語界面 |

<Frame>
  ![右上角帮助中心面板，提供数据看板、助手设置、技能库、知识库和初始化配置引导入口](/images/admin-backend/20-topbar-help-center.png)
</Frame>

<Frame>
  ![右上角语言菜单，提供中文、English 和日本語选项](/images/admin-backend/21-topbar-language-menu.png)
</Frame>

<Tip>
  当你不确定某个模块的入口位置时，优先点击右上角“帮助中心”，选择对应功能板块后开始引导。
</Tip>

## 账号设置

左下角账户区域显示当前账号身份。点击账号设置后，可进入授权码、登录密码和退出登录相关操作。

<Info>
  AI 授权码属于敏感信息，只应提供给被授权的系统或人员，不建议在公开截图、外部文档或聊天中展示完整授权码。
</Info>

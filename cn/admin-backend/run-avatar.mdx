## 功能概览

“登录上线”用于创建和管理 AI 助手的沟通窗口。窗口上线后，AI 才能在对应渠道中接收消息、判断是否回复，并调用知识库或技能库能力。

  ![助手设置中的登录上线页面，包含只显示已上线、显示全部和创建新的沟通窗口按钮](/images/admin-backend/05-assistant-login-online.png)
</Frame>

## 操作路径

在左侧导航点击 **助手设置 → 登录上线**。

## 页面控件

| 控件 | 用途 |
| :--- | :--- |
| 只显示已上线 | 只查看当前在线的沟通窗口 |
| 显示全部 | 查看所有已创建或历史窗口 |
| 创建新的沟通窗口 | 新增一个需要登录或授权的渠道窗口 |

## 创建沟通窗口

<Steps>
  <Step title="点击创建新的沟通窗口">
    在登录上线页面点击“创建新的沟通窗口”。
  </Step>
  <Step title="选择接入渠道">
    在弹窗中选择接入渠道。未选择渠道前，“登录”按钮会保持禁用。
  </Step>
  <Step title="继续登录或授权">
    按渠道提示完成扫码、授权或 URL 配置。URL 渠道需要先设置访问名称。
  </Step>
  <Step title="确认上线状态">
    回到列表后使用“只显示已上线”确认窗口是否在线。
  </Step>
</Steps>

<Frame>
  ![新增沟通窗口弹窗，提示先选择接入渠道，未选择前登录按钮不可点击](/images/admin-backend/22-create-communication-window-modal.png)
</Frame>

<Tip>
  部分渠道完成扫码或授权后需要等待 30 到 60 秒。若列表暂未更新，可稍后刷新或切换“显示全部”查看。
</Tip>

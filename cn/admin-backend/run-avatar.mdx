进入后台后，在左侧菜单打开“助手设置”。  
在右上角选择“新增登录窗口”，并选择您要登录的窗口渠道。  
点击“登录上线”，按提示确认并选好设备位置。  
生成二维码后，用对应设备的APP扫码，并在手机上按照提示连续确认直至登录成功即可。  
<Tip>
  部分情况下登录可能持续30-60秒。请耐心等待。
  完成以上步骤后，您的 AI 助手即成功启动并进入工作状态。若遇到无法扫码或无法确认的情况，请联系系统管理员或业务经理获取帮助。
</Tip>

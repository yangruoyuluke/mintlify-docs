## 功能概览

知识库解决“AI 知道什么”，技能库解决“AI 遇到某类任务时应该怎么做”。如果一个问题不只是问答，而是要计算、判断、查询、生成固定格式结果，就应该考虑做成技能。

## 操作路径

在左侧导航点击 **技能库（Beta）**。

## 先判断这件事适不适合做成技能

如果只是让 AI 知道一条规则，放进知识库就够了；如果需要按步骤执行、调用工具、做条件判断或输出固定格式，就更适合放进技能库。技能开启后，AI 会在匹配场景中尝试调用，所以不要把还没测试稳定的技能直接打开。

## 添加技能

添加技能时，不要只写一个功能名。你需要像给同事写 SOP 一样说明：什么时候触发、需要哪些输入、先做什么、不能做什么、最后应该输出什么。

<Frame>
  ![添加技能页面，包含技能名称、使用概述、详细响应逻辑要求和关联工具选择区](/images/admin-backend/28-add-skill-modal.png)
</Frame>

| 字段 | 写法建议 |
| :--- | :--- |
| 名称 | 使用“动作 + 对象”，例如“产品运输费用计算” |
| 使用概述 | 写给 AI 判断触发场景，例如“客户询问不同地区运费时使用” |
| 详细响应逻辑要求 | 写执行顺序、边界条件、异常处理和输出格式 |
| 关联工具 | 选择技能可调用工具；不选时系统会尝试智能匹配 |

<Warning>
  新技能上线前建议先保持关闭，用测试对话确认触发条件、工具调用和输出格式稳定后再启用。
</Warning>

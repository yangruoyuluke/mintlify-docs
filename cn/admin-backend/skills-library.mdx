## 功能概览

技能库用于定义 AI 助手遇到特定任务时如何执行。知识库解决“AI 知道什么”，技能库解决“AI 怎么做”。

<Frame>
  ![技能库页面，展示技能名称、使用概述、状态开关和添加技能按钮](/images/admin-backend/10-skills-library.png)
</Frame>

## 操作路径

在左侧导航点击 **技能库（Beta）**。

## 查看和启停技能

技能列表展示技能名称、使用概述、状态和操作入口。状态开关开启后，AI 才会在合适场景中调用该技能。

| 字段 | 说明 |
| :--- | :--- |
| 技能名称 | 用于识别技能的短名称 |
| 使用概述 | 说明该技能适合处理什么问题 |
| 状态 | 控制技能是否启用 |
| 操作 | 编辑、查看或管理技能 |

## 添加技能

点击“添加技能”后，可以填写技能名称、使用概述、详细响应逻辑要求，并选择关联工具。

<Frame>
  ![添加技能页面，包含技能名称、使用概述、详细响应逻辑要求和关联工具选择区](/images/admin-backend/28-add-skill-modal.png)
</Frame>

| 字段 | 写法建议 |
| :--- | :--- |
| 名称 | 使用“动作 + 对象”，例如“产品运输费用计算” |
| 使用概述 | 写清何时调用、需要哪些输入、输出什么结果 |
| 详细响应逻辑要求 | 写清执行步骤、边界条件、异常处理和输出格式 |
| 关联工具 | 选择技能可调用工具；不选时系统会尝试智能匹配 |

<Warning>
  新技能上线前建议先保持关闭，用测试对话确认触发条件、工具调用和输出格式稳定后再启用。
</Warning>

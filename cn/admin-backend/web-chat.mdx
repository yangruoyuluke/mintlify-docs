## 功能概览

“网页聊天”用于在后台中直接进入聊天页面。它适合测试响应设定、知识库命中、技能触发和新话术效果。

<Frame>
  ![网页聊天页面，左侧导航定位在网页聊天，主区域为内嵌聊天页面](/images/admin-backend/17-web-chat.png)
</Frame>

## 操作路径

在左侧导航点击 **网页聊天**。

## 推荐测试内容

| 测试类型 | 你应该验证什么 |
| :--- | :--- |
| 人设测试 | AI 是否按响应设定中的身份和口吻回复 |
| 知识测试 | AI 是否能引用正确知识回答常见问题 |
| 边界测试 | AI 是否会避开“不需要回复”的内容 |
| 技能测试 | AI 是否能在对应任务中触发技能逻辑 |
| 线索测试 | AI 是否能自然采集线索字段 |

<Tip>
  每次修改响应设定、知识库或技能库后，建议先在网页聊天中测试，再投入正式客户沟通窗口。
</Tip>

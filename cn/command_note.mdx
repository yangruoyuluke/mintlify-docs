注意，要实现 chat to task，前提条件是您是角色已经认证过的管理员用户对象。

# #登录认证

如果您是AI角色的特殊协作方，例如您是AI角色的同事、导师、或者领导。请直接对您的AI角色输入#auth 进行登录认证。以便可以进一步配置，实现和AI的直接协作，下达指令，等等多方面操作，请谨慎管理您的登录账号密码。登录认证后你可以无需打开电脑，直接用对话管理AI角色的任务执行。

<Info>
  管理认证仅需完成一次，后续无需再次认证。偶尔后台升级后，如需重新认证，也会提示您进行重新认证。
</Info>

<Note>
  请注意：以下内容默认您已经完成#登录认证，如您未完成登录认证，请首先完成上一步登录认证
</Note>


# #培训模式

1. 输入#培训模式，可以实现单条QA知识单元的快速录入。及时补充AI角色的知识范围。请按照指令顺序操作。
2. 如输入#培训模式后，第一步会出现请输入问题。此时请您输入客户会询问的问题。

<Tip>
  如果条件允许，可以对问题和答案QA进行一定完善改写，高质量的输入也会进一步提升AI角色的能力。
</Tip>

3. 完成问题输入后，会提示输入答案。此时输入该问题的答案。
   完整输入后，角色会提示您已完成新的QA录入。此时AI会自动退出培训模式。

# #导师认证

一个AI角色可以配置一个导师，实现AI角色与导师的共同协作，实现当AI遇到待决问题及时向导师报告分析。如果您是AI导师，请输入“#导师认证”进行确认。输入后会出现”导师认证成功的提示“。

<Tip>
  一个AI角色最多可以有1个导师，如果出现其他管理员申请后，该导师角色会被覆盖到新的管理员身上。
</Tip>

# #暂停托管与#继续托管

在特殊情况，例如节假日或者有需要的时候，您可以快速向AI输入”# 暂停托管“或”#继续托管“，实现AI角色的启动状态切换。

# #同事认证

如果您是AI角色的同事，请使用同事认证进行确认。以便AI角色可以分辨用户的角色。

<Info>
  对AI进行同事认证对于智能群聊非常重要，如果需要实现智能群聊，请您务必，尽量让更多的同事操作同事认证。
</Info>

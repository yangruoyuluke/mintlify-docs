这页按时间记录后台的功能变化。最近一轮大更新在 2026-09 ～ 2026-10：左侧导航整合为五个模块，数据看板、知识库、响应设定下的入口有调整，并新增法语、西班牙语界面；更早的更新记录保留在下方。升级后找不到熟悉的入口、或按旧教程对不上界面时，先在这里对一遍。

## 什么时候会用到它

- 升级后发现以前常用的菜单入口不见了。
- 按旧教程或旧截图操作，需要确认某个功能现在的入口名称。
- 想确认某个功能是哪个版本上线的、自己所在的环境有没有。
- 同事交接或培训新人时，需要一份新旧名称对照。

## 进入路径

本页位于文档站：左侧导航 → 开发者文档 → 版本更新。后台里没有对应的菜单页；要动手操作某个功能，从本文条目里的链接或「用户操作指南」进入对应页面。

## 2026-09 ～ 2026-10 大更新

这一轮更新改的是后台结构：菜单整合、入口改名、页面拆分，另外新增两种界面语言。下面按模块列出。

### 导航整合为五个模块

左侧菜单现在只有五组，功能页都归属其中：

| 模块 | 页面 |
| --- | --- |
| 数据看板 | 业务表现、明细数据、AI 用量、会话明细复核 |
| 我的助手 | 登录上线、基础人设、关系配置 |
| 响应设定 | 回复规则、安全围栏、新客户接待、工作时间 |
| 知识库 | 知识生成、知识优化、知识管理 |
| 技能库 | 技能库（列表与编辑） |

左下角「账号设置」菜单里现在是三项：「个人资料」「登录安全」「AI 身份授权」；同一菜单里还有「语言」和「退出登录」。原「网页聊天」页面不再提供。

### 数据看板

- 「AI 用量」：查看剩余额度和每月消耗，只对部门管理员显示。详见 [AI 用量](/cn/guide/dashboard/ai-usage)。
- 新增「会话明细复核」：美客多业务的会话复核页，打开后是内嵌的复核应用，筛选与列表都在应用内完成；只对美客多业务部门或平台管理员显示。详见 [会话明细复核](/cn/guide/dashboard/conversation-review)。
- 「明细数据」：筛选、查看和导出沟通记录。详见 [明细数据](/cn/guide/dashboard/data-export)。

### 知识库

- 三个入口改名：「知识创建」→「知识生成」，「知识管理」→「知识优化」，「知识分组」→「知识管理」。
- 改名后的分工：知识生成把文档、网页或现成问答变成知识；知识优化审核待入库的知识、处理 AI 答不上来的问题；知识管理维护分组结构，并检索、编辑已入库知识。

### 响应设定

- 原来集中在「响应设定」一页里的配置，现在分开管理：AI 的人设与主提示词在「我的助手 → 基础人设」；不知道答案时怎么回、群里怎么响应、什么时候主动汇报在「响应设定 → 回复规则」。
- 「关键词直出」从「新客户接待」移到了「回复规则」。
- 「安全围栏」「新客户接待」「工作时间」与「回复规则」一起归入「响应设定」模块。

### 界面语言

- 新增法语（Français）和西班牙语（Español）界面，后台现在支持五种界面语言：中文、English、日本語、Français、Español。
- 切换方式：左下角「账号设置」→「语言」。
- 「会话明细复核」内嵌的是外部应用，只识别部分界面语言；在法语、西班牙语下它会显示英文。

### 名称对照

找旧入口时先查这张表：

| 更新前的名称 | 现在的名称 |
| --- | --- |
| 订单用量 | AI 用量 |
| 明细复核 | 明细数据 |
| 知识创建 | 知识生成 |
| 知识管理 | 知识优化 |
| 知识分组 | 知识管理 |
| 关系管理 | 关系配置 |
| 线索清洗 | 新客户接待 |

注意：「知识管理」在新旧版本里不是同一个页面——更新前的「知识管理」是现在的「知识优化」；更新后的「知识管理」是原来的「知识分组」。与同事按旧叫法沟通时，先确认对方指哪一个。

## 更早的更新（仍然有效）

- **2026-08-25 · 新增「安全围栏」**：在 AI 回复发出之前判断风险，按规则拦截、放行或通知主管。位置：「响应设定 → 安全围栏」，见 [安全围栏](/cn/guide/response/safety-guardrails)。
- **2025-09-05 · 新增「关系配置」**（当时称「关系管理」）：集中设置联系人和群与 AI 的关系（客户、同事、静默、主管）；「静默」让指定的人或群不触发 AI 响应。见 [关系配置](/cn/guide/assistant/relationship-config)。
- **2025-08-15 · 管理后台 v0.1.0 上线**：开放后台登录与知识库管理能力。
- **2025-06-10 · 日报、周报能力上线**：助手可以汇总业务进展；可以在对话里让它「开启日报」「关闭日报」「开启周报」「关闭周报」。

## 操作步骤

升级后按这三步把入口对上：

<Steps>
  <Step title="确认你用的是新版后台">
    看左侧菜单是不是五个模块：数据看板、我的助手、响应设定、知识库、技能库；再看左下角「账号设置」菜单里有没有「个人资料」「登录安全」「AI 身份授权」三项。

    判断标准：五个模块齐全，且左下角「账号设置」里有这三项。结构对不上时，先核对你的环境是否已更新到这一版，再按本页记录操作。
  </Step>

  <Step title="用「名称对照」表把旧名翻成新名">
    拿你要找的旧入口在「名称对照」表里查一次。例如记得「订单用量」就查「AI 用量」，记得「线索清洗」就查「新客户接待」。

    判断标准：要用的旧名都能查到唯一的新名称，然后按「左侧菜单 → 模块 → 页面」打开，例如「左侧菜单 → 知识库 → 知识生成」。

    注意：「知识管理」新旧含义不同，别直接按旧记忆进入，先看表下的说明。
  </Step>

  <Step title="打开页面核对后再动手">
    打开对应页面，先看标题和页面说明是不是你要找的功能，再按「用户操作指南」里该页的步骤修改配置。

    判断标准：页面标题与新名称一致、内容能正常加载。看不到「AI 用量」或「会话明细复核」的入口时，先按常见问题检查权限，不必反复翻菜单。
  </Step>
</Steps>

## 检查点

- 左侧菜单是「数据看板 / 我的助手 / 响应设定 / 知识库 / 技能库」五个模块。
- 左下角「账号设置」里能找到「个人资料」「登录安全」「AI 身份授权」，以及「语言」「退出登录」。
- 你要找的旧入口都能在「名称对照」表里查到现在的名称。
- 需要切换语言时，能在「账号设置 → 语言」里看到五种语言。

## 注意事项

<Warning>
「AI 用量」只对部门管理员显示，「会话明细复核」只对美客多业务部门或平台管理员显示；其余账号看不到菜单，直接访问会显示「无权限访问」。看不到这两个入口是权限差异，不是版本没更新。
</Warning>

<Info>
「响应设定」在本次更新后是模块名，包含「回复规则」「安全围栏」「新客户接待」「工作时间」四个页面；旧教程里说的「响应设定」是更新前的一个单页配置，两者不是一回事。
</Info>

<Tip>
顶栏「帮助与引导」里的「帮助中心」可以帮你熟悉新入口：选「数据看板 / 助手设置 / 知识库 / 技能库」任一张引导卡，页面会分步高亮对应入口；点「初始化配置」还能按引导走一遍助手登录、使用规则、知识库三项基础配置。
</Tip>

## 常见问题

### 以前在「响应设定」里改的内容，现在到哪里改？

拆到了两个页面：AI 的人设与主提示词在「我的助手 → 基础人设」；不知道答案时怎么回、群里怎么响应、什么时候主动汇报、关键词直出在「响应设定 → 回复规则」。安全围栏、新客户接待、工作时间仍是独立页面，也在「响应设定」下。操作见 [基础人设](/cn/guide/assistant/persona) 和 [回复规则](/cn/guide/response/reply-rules)。

### 「知识创建」「知识分组」怎么找不到了？

改名了，功能还在：知识创建 → 知识生成，知识管理 → 知识优化，知识分组 → 知识管理。注意「知识管理」现在的含义是分组结构与已入库知识的维护，和以前叫「知识管理」的页面（现在叫「知识优化」）不是同一个入口。

### 为什么我的账号看不到「AI 用量」或「会话明细复核」？

权限不同：「AI 用量」只对部门管理员开放；「会话明细复核」只对美客多业务部门或平台管理员开放。其他账号看不到菜单，直接访问会显示「无权限访问」，与后台版本无关。

### 旧教程、旧截图还能照着操作吗？

按旧结构写的部分（旧菜单名、旧入口位置）已经对不上，请以本站「用户操作指南」的当前页面为准；本页只保留仍然有效的更新记录。旧教程里提到的「网页聊天」入口，新版后台不再提供。

### 界面语言在哪里切换？为什么「会话明细复核」还是英文？

左下角「账号设置」→「语言」，可选 中文、English、日本語、Français、Español 五种。「会话明细复核」内嵌的是外部应用，只识别部分界面语言：切到法语或西班牙语时，它仍会显示英文。

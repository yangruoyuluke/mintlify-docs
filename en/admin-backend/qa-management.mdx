# QA Management

> Manage knowledge units in a structured way.

### 1. QA Search

Enter your search query in the top search bar and press Enter. Each blue-framed box in the results represents a knowledge unit, displayed as a Question-Answer pair (QA).

Blue rounded rectangles represent tags, and the light gray text shows the QA source.

<Info>
  Note: This search uses vector-based semantic search, which is different from traditional keyword search. It searches by understanding the meaning of your input. For example, searching for “desk lamp” may also return related content like “appliances.”
</Info>

![Screenshot 2025-07-18 at 22.46.05.png](/images/Screenshot2025-07-18at22.46.05.png)

2. If you have a large number of documents, use the filter on the right to further narrow down results by QA source.

### 2. QA Editing

- Double-click the QA you wish to edit to open it. Alternatively, use the edit or delete icon in the lower right corner of each QA to open the edit dialog.

![Screenshot 2025-07-18 at 22.55.20.png](/images/Screenshot2025-07-18at22.55.20.png)

- If the edit box is too small, you can drag the bottom right corner to resize it. You can freely expand and scroll to make editing easier.
- You can edit the question, answer, and document source. For document source, you may create a new document or select an existing one to save the QA.

![Screenshot 2025-07-18 at 22.55.34.png](/images/Screenshot2025-07-18at22.55.34.png)

### 3. Adding QA

Use the “Add” button in the upper right corner to add a single QA, or use the “Batch” button to add multiple QAs at once.

![Screenshot 2025-07-18 at 22.54.30.png](/images/Screenshot2025-07-18at22.54.30.png)

#### Add a Single QA

Click “Add” to open the new QA entry window. After editing, you can choose “Save and Continue” to keep adding single QAs, or click the dark blue “Add QA” button to add just one.

![Screenshot 2025-07-18 at 23.21.28.png](/images/Screenshot2025-07-18at23.21.28.png)

#### Batch Add QAs

1. Click the “Batch” button to open the batch QA upload dialog.

![Screenshot 2025-07-18 at 23.21.35.png](/images/Screenshot2025-07-18at23.21.35.png)

2. If this is your first time, you can download a sample Excel template. Start from the second row and enter your questions and answers—each row should contain one question and its corresponding answer. After editing, save your document and prepare it for upload.

![Screenshot 2025-07-18 at 23.23.55.png](/images/Screenshot2025-07-18at23.23.55.png)

3. Select the file you want to upload and click the “Upload” button. The batch QA import will then be complete.

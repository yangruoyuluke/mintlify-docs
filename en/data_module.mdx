## Top Metrics

The top of the page displays several key indicators:

- **Total Message Count**: Cumulative total messages
- **Customers Served**: Number of customers served
- **Online AI Sales**: Number of currently online AI sales
- **Daily AI Performance**: Daily average performance data

---

## Trend Charts

- **Ticket by Date**\
  Display message trends by time dimension.
  - X-axis: Date (displayed by day)
  - Y-axis: Message count
  - Different colored curves represent different Avatars (such as Avatar1, Avatar2, Avatar3, etc.)

Here you can intuitively see the message activity of each role in different time periods.

---

## Question Classification

Below the trend chart (area not fully shown in screenshot), the system will intelligently classify and rank questions raised by customers, for example:

- Category name
- Percentage proportion

Through classification, you can more clearly see the composition of common customer questions.

## Data Export

The page supports exporting data for enterprises to conduct further analysis or archiving.

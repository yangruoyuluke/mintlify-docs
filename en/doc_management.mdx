# File Upload

Click the user icon in the sidebar menu to enter the file management page.

![Screenshot 2025-07-18 at 23.37.19.png](/images/Screenshot2025-07-18at23.37.19.png)

Click the Upload File button to open a pop-up window prompting you to select the file you wish to upload. After confirming your selection, the file upload will begin and the system will automatically parse the file in the background.

![Screenshot 2025-07-18 at 23.37.37.png](/images/Screenshot2025-07-18at23.37.37.png)

Once the upload and parsing are complete, a “ready” notification will appear in the status bar. At this point, the corresponding file has been parsed into QA knowledge units and saved to your QA collection.

![Screenshot 2025-07-18 at 23.41.23.png](/images/Screenshot2025-07-18at23.41.23.png)

![Screenshot 2025-07-18 at 23.37.41.png](/images/Screenshot2025-07-18at23.37.41.png)

<Info>
  For larger files, processing may take 5–10 minutes.
</Info>


# File Deletion

If a file no longer reflects the latest business knowledge, or if you need to make periodic adjustments to your knowledge base, you can select and delete the relevant files. You can also select multiple files for batch deletion.

![Screenshot 2025-07-18 at 23.42.14.png](/images/Screenshot2025-07-18at23.42.14.png)

Deleted files are moved to the recycle bin. From here, you can choose to restore any files, making the corresponding knowledge active again.

![Screenshot 2025-07-18 at 23.42.14.png](/images/Screenshot2025-07-18at23.42.14.png)

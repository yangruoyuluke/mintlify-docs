## API 接口

我们提供完整的 RESTful API，支持：

```bash
# 获取用户信息
GET /api/v1/users/{id}

# 创建新项目
POST /api/v1/projects
{
  "name": "项目名称",
  "description": "项目描述"
}

# 更新项目状态
PUT /api/v1/projects/{id}/status
{
  "status": "active"
}
```

<Tip>
查看完整的 [API 文档](https://api.yourcompany.com/docs) 获取更多信息。
</Tip>

## 機能紹介

このページは新規ユーザーがAI友達を追加する際のインタラクションロジックを設定するために使用され、以下が含まれます：

1. **友達申請を自動承認するかどうか**
2. **新規対話ユーザー歓迎メッセージ（テキスト/ファイル/画像をサポート）**
3. **リード清洗と情報収集**

---

## 友達申請の自動承認

- スイッチをオンにすると、システムは自動的にすべての新規友達リクエストを承認します。
- オフの場合、手動で追加するかどうかを確認する必要があります。
- 推奨：
  - **広範囲な顧客開拓**を目指す場合 → 自動承認をオン
  - **正確な制御または小規模試験**を目指す場合 → オフのまま

## 新規対話ユーザー歓迎メッセージ

<Frame>
  ![Screenshot 2025-09-06 at 23.55.03.png](/images/Screenshot2025-09-06at23.55.03.png)
</Frame>

- システムは **最大6つの歓迎メッセージ** の設定をサポートします。
- 各歓迎メッセージは以下から選択できます：
  - **テキスト**：最大200文字の挨拶または説明を入力
  - **ファイル**：紹介文書、プロセス資料など
  - **画像**：ブランドKV、操作ガイドなど

<Info>
  異なるシナリオに合わせて歓迎メッセージを設計し、順序に従って送信できます：

  - 一般的な挨拶（例：「こんにちは、追加いただきありがとうございます。こちらは…」）
  - サービス約束（例：「24時間以内の応答をお約束します」）
  - ビジネス紹介（例：「AIが出品、アフターサービス関連の質問にお答えします」）
  - 資料案内（例：「詳細情報は添付文書/公式サイトリンクをご覧ください」）
</Info>

## リード清洗と情報収集

<Frame>
  ![Screenshot 2025-09-06 at 23.55.07.png](/images/Screenshot2025-09-06at23.55.07.png)
</Frame>

新規ユーザーが対話に入ると、AIは設定に基づいて自動的に相手に重要な情報の入力を案内し、企業が迅速に顧客プロファイルを構築するのを支援します。

- **清洗要素**：収集が必要なフィールド（メールアドレス、会社名、顧客名、GMVなど）。
- **説明**：フィールドの簡潔な説明で、ユーザーの理解を助けます。
- **例**：サンプル形式を提供し、ユーザーの入力混乱を避けます。

<Tabs>
  <Tab title="設定例">
    | 清洗要素 | 説明          | 例                  |
    | :--- | :---------- | :------------------ |
    | メールアドレス   | 今後のコミュニケーション用の常用メールアドレス | `xxx@gmail.com`     |
    | 会社略称 | 企業または店舗の略称    | "星智科技" / "MarsMind" |
    | GMV  | 年間店舗収入流水    | `40万米ドル / 1000万人民元`  |
    | 主要カテゴリ | 主要販売品目の方向   | "家具・インテリア" / "ペット用品"     |
  </Tab>
</Tabs>

<Info>
  推奨
  - 自社のビジネスニーズに応じて収集要素を柔軟に設定し、過多または過少を避けます。
  - システムは一括追加と保存をサポートし、反復最適化を容易にします。
  - 収集された情報は顧客プロファイルに蓄積され、AIアシスタントは今後ビジネス分析処理をアップグレードし、あなたに通知します。
</Info>

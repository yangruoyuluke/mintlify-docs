このページは、管理画面の機能変更を時系列で記録したものです。直近の大規模アップデートは 2026-09 ～ 2026-10 に実施され、左側メニューが5つのモジュールに統合されました。データダッシュボード、ナレッジベース、応答設定では入口が変更され、フランス語とスペイン語の画面も追加されています。以前の更新記録はこの下に残しています。アップデート後に見慣れた入口が見つからないときや、古いチュートリアルと画面が一致しないときは、まずこのページで確認してください。

## このページが必要なとき

- アップデート後、以前よく使っていたメニューの入口が見当たらない。
- 古いチュートリアルやスクリーンショットのとおりに操作する前に、その機能の現在の入口名を確認したい。
- ある機能がどのバージョンで提供されたか、自分の環境にあるかを確認したい。
- 引き継ぎや新人研修のために、新旧の名称対照表がほしい。

## アクセス方法

このページはドキュメントサイト内にあります：左側ナビゲーション → 開発者向けドキュメント → バージョン更新。管理画面に対応するメニューページはありません。機能を実際に操作するときは、本文中のリンクまたは「操作ガイド」から該当ページを開いてください。

## 2026-09 ～ 2026-10 の大規模アップデート

今回のアップデートでは、管理画面の構造が変わりました：メニューの統合、入口の名称変更、ページの分割、そして2つの表示言語の追加です。以下、モジュールごとに説明します。

### ナビゲーションを5つのモジュールに統合

左側メニューは現在5つのグループだけで、すべての機能ページがいずれかに属します：

| モジュール | ページ |
| --- | --- |
| データダッシュボード | ビジネスパフォーマンス、明細データ、AI利用量、会話明細レビュー |
| マイアシスタント | ログイン・稼働、基本ペルソナ、関係設定 |
| 応答設定 | 返信ルール、安全ガードレール、新規顧客対応、稼働時間 |
| ナレッジベース | ナレッジ生成、ナレッジ最適化、ナレッジ管理 |
| スキルライブラリ | スキルライブラリ（一覧と編集） |

左下の「アカウント設定」メニューは現在3項目です：「プロフィール」「ログインのセキュリティ」「AI 役割認証」。同じメニューには「言語」と「ログアウト」もあります。以前の「Webチャット」ページは提供されなくなりました。

### データダッシュボード

- 「AI利用量」：残りのポイントと月ごとの使用量を確認できます。部門管理者にのみ表示されます。詳しくは [AI利用量](/jp/guide/dashboard/ai-usage) を参照してください。
- 「会話明細レビュー」を新規追加：Mercado 業務の会話レビューページです。開くとレビューアプリが埋め込まれて表示され、絞り込みとリストの操作はアプリ内で行います。Mercado 部門または管理者にのみ表示されます。詳しくは [会話明細レビュー](/jp/guide/dashboard/conversation-review) を参照してください。
- 「明細データ」：会話記録を絞り込み、確認・出力します。詳しくは [明細データ](/jp/guide/dashboard/data-export) を参照してください。

### ナレッジベース

- 3つの入口が名称変更されました：「ナレッジ作成」→「ナレッジ生成」、「ナレッジ管理」→「ナレッジ最適化」、「ナレッジグループ」→「ナレッジ管理」。
- 名称変更後の役割分担：ナレッジ生成はドキュメント、ウェブページ、既存の Q&A をナレッジに変換します。ナレッジ最適化は登録前のナレッジを審査し、AI が答えられなかった質問に対応します。ナレッジ管理はグループ構造を維持し、登録済みナレッジの検索と編集を行います。

### 応答設定

- 以前は「応答設定」の1ページにまとまっていた設定が、分けて管理されるようになりました。AI のペルソナとメインプロンプトは「マイアシスタント → 基本ペルソナ」、不明時の返信、グループへの応答、自発的な報告は「応答設定 → 返信ルール」です。
- 「キーワード直接応答」は「新規顧客対応」から「返信ルール」に移動しました。
- 「安全ガードレール」「新規顧客対応」「稼働時間」は「返信ルール」とともに「応答設定」モジュールに属します。

### 表示言語

- フランス語（Français）とスペイン語（Español）の画面が追加され、管理画面は5つの表示言語に対応しました：中文、English、日本語、Français、Español。
- 切り替え方法：左下の「アカウント設定」→「言語」。
- 「会話明細レビュー」は外部アプリを埋め込んでいるため、一部の表示言語しか認識しません。フランス語またはスペイン語では英語で表示されます。

### 名称対照表

古い入口を探すときは、まずこの表を確認してください：

| 更新前の名称 | 現在の名称 |
| --- | --- |
| 注文使用量 | AI利用量 |
| 明細レビュー | 明細データ |
| ナレッジ作成 | ナレッジ生成 |
| ナレッジ管理 | ナレッジ最適化 |
| ナレッジグループ | ナレッジ管理 |
| 関係管理 | 関係設定 |
| リードクリーニング | 新規顧客対応 |

注意：「ナレッジ管理」は新旧で同じページではありません。更新前の「ナレッジ管理」は現在の「ナレッジ最適化」で、更新後の「ナレッジ管理」は以前の「ナレッジグループ」です。同僚と古い呼び方で話すときは、どちらを指しているかを先に確認してください。

## 以前のアップデート（現在も有効）

- **2026-08-25 · 「安全ガードレール」追加**：AI の返信が送信される前にリスクを判定し、ルールに従って遮断・許可・責任者への通知を行います。場所：「応答設定 → 安全ガードレール」。詳しくは [安全ガードレール](/jp/guide/response/safety-guardrails) を参照してください。
- **2025-09-05 · 「関係設定」追加**（当時は「関係管理」）：連絡先やグループと AI の関係（顧客、同僚、自動返信なし、責任者）をまとめて設定できます。「自動返信なし」にした相手やグループには、AI が応答しません。詳しくは [関係設定](/jp/guide/assistant/relationship-config) を参照してください。
- **2025-08-15 · 管理画面 v0.1.0 公開**：管理画面へのログインとナレッジベース管理の機能を提供開始。
- **2025-06-10 · 日報・週報機能を提供開始**：アシスタントが業務の進捗をまとめられるようになりました。会話の中で「日報を有効化」「日報を無効化」「週報を有効化」「週報を無効化」と依頼できます。

## 操作手順

アップデート後は、次の3ステップで入口を照合します：

<Steps>
  <Step title="新しい管理画面を使っているか確認する">
    左側メニューが5つのモジュール——データダッシュボード、マイアシスタント、応答設定、ナレッジベース、スキルライブラリ——になっているか確認します。続けて、左下の「アカウント設定」メニューに「プロフィール」「ログインのセキュリティ」「AI 役割認証」の3項目があるか確認します。

    判断の目安：5つのモジュールがそろっており、左下の「アカウント設定」にこの3項目があること。構造が一致しない場合は、まず自分の環境がこのバージョンに更新済みかを確認し、そのうえでこのページの記録に従って操作してください。
  </Step>

  <Step title="「名称対照表」で旧名称を現在の名称に読み替える">
    探している旧入口を「名称対照表」で一度確認します。たとえば「注文使用量」を覚えているなら「AI利用量」、「リードクリーニング」を覚えているなら「新規顧客対応」を調べます。

    判断の目安：探している旧名称がすべて、対応する現在の名称を1つに特定できること。その後は「左側メニュー → モジュール → ページ」で開きます。たとえば「左側メニュー → ナレッジベース → ナレッジ生成」です。

    注意：「ナレッジ管理」は新旧で意味が異なります。昔の記憶のまま直接開かず、まず表の下の説明を確認してください。
  </Step>

  <Step title="ページを開いて確認してから操作する">
    該当ページを開き、タイトルとページの説明が探している機能のものかを先に確認してから、「操作ガイド」の該当ページの手順に従って設定を変更します。

    判断の目安：ページのタイトルが新しい名称と一致し、内容が正常に読み込まれること。「AI利用量」または「会話明細レビュー」の入口が見つからない場合は、メニューを何度も見直さず、先に「よくある質問」に沿って権限を確認してください。
  </Step>
</Steps>

## チェックポイント

- 左側メニューが「データダッシュボード / マイアシスタント / 応答設定 / ナレッジベース / スキルライブラリ」の5つのモジュールになっている。
- 左下の「アカウント設定」に「プロフィール」「ログインのセキュリティ」「AI 役割認証」、および「言語」「ログアウト」が見つかる。
- 探している旧入口の現在の名称を、すべて「名称対照表」で確認できる。
- 言語を切り替えたいとき、「アカウント設定 → 言語」に5つの言語が表示される。

## 注意事項

<Warning>
「AI利用量」は部門管理者にのみ、「会話明細レビュー」は Mercado 部門または管理者にのみ表示されます。そのほかのアカウントではメニューに表示されず、直接開くと「アクセス権限がありません」と表示されます。この2つの入口が見えないのは権限の違いであり、バージョンが更新されていないわけではありません。
</Warning>

<Info>
「応答設定」は今回のアップデート以降、モジュール名です。「返信ルール」「安全ガードレール」「新規顧客対応」「稼働時間」の4ページを含みます。古いチュートリアルでいう「応答設定」は更新前の1ページの設定であり、両者は別物です。
</Info>

<Tip>
上部バーの「ヘルプとガイド」にある「ヘルプセンター」は、新しい入口の把握に役立ちます。「データダッシュボード / アシスタント設定 / ナレッジベース / スキルライブラリ」のいずれかのガイドカードを選ぶと、対応する入口がページ上で順にハイライト表示されます。「初期設定ガイド」を開始すると、アシスタントログイン、利用ルール、ナレッジベースの3つの基本設定を案内に沿って順に進められます。
</Tip>

## よくある質問

### 以前「応答設定」で変更していた内容は、今どこで変更しますか？

2つのページに分かれました。AI のペルソナとメインプロンプトは「マイアシスタント → 基本ペルソナ」、不明時の返信、グループへの応答、自発的な報告、キーワード直接応答は「応答設定 → 返信ルール」です。安全ガードレール、新規顧客対応、稼働時間は引き続き独立したページで、「応答設定」の下にあります。操作は [基本ペルソナ](/jp/guide/assistant/persona) と [返信ルール](/jp/guide/response/reply-rules) を参照してください。

### 「ナレッジ作成」「ナレッジグループ」が見つからないのはなぜですか？

名称が変わりましたが、機能は残っています：ナレッジ作成 → ナレッジ生成、ナレッジ管理 → ナレッジ最適化、ナレッジグループ → ナレッジ管理。現在の「ナレッジ管理」はグループ構造と登録済みナレッジの維持を指し、以前「ナレッジ管理」と呼ばれていたページ（現在の「ナレッジ最適化」）とは別の入口です。

### 自分のアカウントで「AI利用量」や「会話明細レビュー」が見えないのはなぜですか？

権限が異なるためです：「AI利用量」は部門管理者にのみ公開されており、「会話明細レビュー」は Mercado 部門または管理者にのみ公開されています。そのほかのアカウントではメニューに表示されず、直接開くと「アクセス権限がありません」と表示されます。管理画面のバージョンとは関係ありません。

### 古いチュートリアルやスクリーンショットのとおりに操作できますか？

旧構造に沿って書かれた部分（旧メニュー名、旧入口の位置）は、現在の画面とは一致しません。本サイト「操作ガイド」の現在のページを基準にしてください。このページには現在も有効な更新記録だけを残しています。古いチュートリアルにある「Webチャット」の入口は、新しい管理画面では提供されません。

### 表示言語はどこで切り替えますか？「会話明細レビュー」が英語のままなのはなぜですか？

左下の「アカウント設定」→「言語」で、中文、English、日本語、Français、Español の5つから選べます。「会話明細レビュー」は外部アプリを埋め込んでいるため、一部の表示言語しか認識しません。フランス語またはスペイン語に切り替えると、英語のまま表示されます。
